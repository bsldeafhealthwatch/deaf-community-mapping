# Prompt 39 — Naming shortlist: clarity, distinctiveness, existing-use conflicts

**Master index prompt 39.** Second file in the Deaf Access Gap Monitor / BSL Policy Maker scoping batch (prompts 38–45). Compiled 8–9 September 2026. Dossier rule: stay unbiased; follow money and fulfilment. An unsourced AI claim is the lowest tier. Gaps are logged as gaps.

**What this prompt is for.** Test five working names against (a) existing UK organisational or product use, (b) false-authority risk — a name that could be read as an NHS, government or regulator product, given the tool would report on those same bodies — and (c) domain and social-handle availability. Prompt 38 already flagged that an official-sounding name is a specific risk to avoid.

**Names under test**

1. Deaf Access Gap Monitor
2. BSL Accountability Tracker
3. AIS Compliance Monitor
4. Deaf Policy Ledger
5. Access Gap Register

**Limitation on this pass.** Companies House name search, Charity Commission web hits, IPO trade-mark text search via public results, general web search, and X handle search were run on 8–9 September 2026. Direct `whois` from this environment returned empty on several strings; domain status below is therefore “no live site found on web search” rather than a registrar-confirmed available/taken flag. A solicitor or naming agent should re-run IPO word-mark search by Nice class and Nominet/ICANN WHOIS before any filing. That is a gap, not a clearance.

---

## Headline

None of the five strings is an exact Companies House or live UK product name. That is the easy part. The hard part is that **three of the five read as if they could be official**, and the two that do not still collide with occupied *word families*.

Highest official-sounding risk: **AIS Compliance Monitor** and **Access Gap Register**. Both use vocabulary NHS England, CQC and the BSL Act reports already own (“compliance”, “monitor”, “register”). Using either as a public-facing name would create the false-authority problem prompt 38 warned about.

Highest existing-use collision in the *word family*, not the exact string: **Deaf Access Gap Monitor**. Companies House already holds **Deaf Access Trust** (02705030, live since 1992, charity 1010731), **Deaf Accessibility C.I.C.** (11414390), and **Deaf Access NI Limited** (NI720038, incorporated August 2024). `deafmonitor.com` is a live global Deaf news platform launched April 2026. `deafaccess.com` is a US interpreting agency.

The mySociety convention — plain English, second-person or street-level, obviously not a department — still looks the better fit. None of the five candidates is in that convention.

---

## How the test was applied

For each name:

- **(a) Existing use.** Exact string on the open web; Companies House name search; Charity Commission hits; close variants that a reasonable person would confuse.
- **(b) Official-sounding risk.** Would a journalist, ICB officer or select-committee clerk reasonably think this was an NHS England, DHSC, CQC, EHRC or Cabinet Office Disability Unit product? Flag if yes.
- **(c) Domain / handle.** Exact `.com` / `.co.uk` / `.org.uk` live sites found; X handles found. Not a full handle sweep across Instagram, Bluesky, TikTok.

Trade-mark note used throughout: no *exact* UK word-mark for any of the five full strings was found on this pass. Nearby marks exist on the word **GAP** (several registered marks carry an explicit disclaimer of exclusive rights in “GAP”). **SIGNPORT** is registered to Deaf Action (UK00004284235, filed 27 Oct 2025, registered 16 Jan 2026). **DEAF ATHLETIC** is a protected international mark. None of those is a block on the five strings, but “GAP” and “DEAF …” are crowded fields.

## 39.2 BSL Accountability Tracker

### (a) Existing use

Exact string: **not found**.

Collisions and overloads:

- **BSL** in a UK health/civic context means British Sign Language. In a clinical context it also means the **Borderline Symptom List** (BSL-23 / BSL-95). A live US therapy page already sells a “Borderline Personality Disorder Symptom Severity Tracker (BSL-Informed)”. A clinician Googling the name will get the wrong BSL first.
- **Accountability Tracker** is a generic product category (3mpwrApp in Canada; habit/accountability apps). Not a UK official body.
- **BLSA Reform Tracker** (Business Leadership South Africa, tracker.blsa.org.za, launched Aug 2025) is a near-anagram collision in search, not a UK problem.
- Companies House “ACCOUNTABILITY TRACKER” search returns a long list of accountancy firms using “Accountability …” (Accountability Tax & Payroll, Accountability FD, Accountability Access UK Limited, etc.). No “BSL Accountability Tracker”.
- BSL Act official reports already occupy “BSL report” / “BSL plan”. A “BSL Accountability Tracker” could be misread as the statutory report’s public front-end.

### (b) Official-sounding risk

**Medium–high.** “Accountability” plus “Tracker” is the register’s language (EHRC Human Rights Tracker; IfG Performance Tracker; Scottish Human Rights Tracker; Climate Action Scorecards). A clerk could reasonably ask whether this was the Disability Unit’s implementation dashboard for the BSL Act. Prompt 38’s rule was: do not claim to be the BSL Act monitor. This name does that work for you, unasked.

### (c) Domain / handle

- Exact live site: not found.
- `@BSLTracker` / `@BSLAccountability` — no matching X user found on this pass (X user search for “BSL Tracker” returned packers-and-movers and BSL-teaching accounts, not a tracker product).
- `.co.uk` / `.org.uk` exact: no live site found.

### Verdict

Functionally clearer than “Deaf Access Gap Monitor” for a BSL-first audience. Official-sounding risk is the binding constraint. If kept, it needs a visibly non-governmental host and a subtitle that says who runs it (“an independent civic dataset”, not “the BSL tracker”).

## 39.3 AIS Compliance Monitor

### (a) Existing use

Exact string: **not found** as a company or product.

The components are heavily occupied inside the NHS:

- **AIS** in this dossier means Accessible Information Standard (DAPB1605). In the same week’s search it also means Automatic Identification System, various company prefixes (AISO Compliance & Training Limited is on Companies House), and assorted clinical abbreviations.
- **Compliance monitor / compliance monitoring** is ordinary NHS operational language. National Infection Prevention and Control Manual hosts a “Compliance monitoring” tool. NHS England historically published “Data on patient safety alert compliance”. Assuric markets itself as an NHS digital-health “compliance, governance and assurance platform”. Actually AI (UK) sells a “Compliance Monitor” for AIM and Main Market issuers. UT Compliance publishes an “Accessible Information and Communication Policy” that name-checks AIS 2025, the Equality Act and the BSL Act — a care-provider policy template, not this project, but the phrase cluster is the same.
- NHS England’s own AIS pages already tell organisations to *assess compliance*, publish a RAG, and appoint an AIS lead. A public site called “AIS Compliance Monitor” looks like the missing national dashboard that NHS England has chosen not to build.

### (b) Official-sounding risk

**High — do not use as the public name.** This is the one name on the list that a reasonable ICB or trust officer would file under “is this NHS England?” It also inherits the AIS-only scope problem: the tool as scoped in prompt 38 covers BSL Act + Equality Act + AIS + spend, not AIS alone. Naming it for one standard shrinks the claim and invites “why aren’t you the official self-assessment?”

### (c) Domain / handle

- Exact live site: not found.
- No X handle collision found on the exact string.

### Verdict

Reject for public-facing use. Fine as an *internal* dataset name for the AIS slice (“AIS compliance tab”) once the public product has a different name.

## 39.4 Deaf Policy Ledger

### (a) Existing use

Exact string: **not found**. Companies House “POLICY LEDGER” search returned no matching company on the results page retrieved.

“Ledger” in 2026 UK usage leans finance, audit, or distributed-ledger / blockchain. It does not mean “policy register” to a BSL user or a council DASS. “Deaf Policy” as a phrase is not a trading name found on this pass.

### (b) Official-sounding risk

**Low–medium.** Does not sound like an NHS product. Sounds like a specialist publication or a think-tank notebook. The risk is opacity, not false authority: a select-committee clerk will not know what a “policy ledger” contains.

### (c) Domain / handle

- Exact live site: not found.
- Handles not found on this pass.

### Verdict

Least collision of the five, weakest communication of what the thing *does*. A ledger does not, in ordinary English, flag a gap between a statute and an invoice. Keep only if the product is deliberately positioned as a sourced running record rather than a scorecard.

## 39.5 Access Gap Register

### (a) Existing use

Exact string: **not found**.

Companies House “ACCESS GAP” search returned adjacent but unrelated names (Accountancy Gap Services, The Advice Gap Limited, Age Gap Limited, Air Gap Network Security, The Alignment Gap Ltd). No “Access Gap Register”.

“Register” is the problem word. In this sector it already means:

- NRCPD register of sign-language interpreters and RIDB
- CQC provider register
- NHS Spine / Personal Demographics Service
- The proposed (and not built) national AIS needs flag as a *register of needs*
- Companies House register, charity register

“Access Gap” as two words also collides with transport and digital-inclusion “access gap” literature, and with registered marks that include GAP (several IPO records explicitly disclaim exclusive rights in “GAP” — e.g. UK00004015864, UK00003482749). That disclaimer cuts both ways: you can probably use “gap”, and so can everyone else.

### (b) Official-sounding risk

**High.** “Register” is what the state runs. A public “Access Gap Register” that names NHS trusts and local authorities for non-delivery will be read, by those bodies’ comms teams, as either an official list or a naming-and-shaming list pretending to be official. Prompt 45 will cover liability; the name itself creates the fight.

### (c) Domain / handle

- Exact live site: not found.
- No X handle collision found.

### Verdict

Reject for public-facing use for the same reason as AIS Compliance Monitor: official vocabulary applied to an unofficial product.

## 39.7 The mySociety convention — does it fit this project better?

Yes. The documented reason mySociety renamed Neighbourhood Fix-It to **FixMyStreet** in June 2007 was that the first name was “a bit of a mouthful, hard to spell, and hard to publicise (does the URL have a dash in it or not?)”. TheyWorkForYou, WhatDoTheyKnow, WriteToThem and FixMyStreet are second-person or street-level English. None of them could be mistaken for a departmental statistical release. That is the property this project needs, because its function is to hold NHS and local-authority bodies to account.

Sources for that convention:

- FixMyStreet rename post — mySociety, 16 June 2007. <https://www.mysociety.org/2007/06/16/fixmystreet/>
- About mySociety. <https://www.mysociety.org/about/>
- History — TheyWorkForYou launched 2004 (adopted 2006); WriteToThem 2005; FixMyStreet 2007. <https://www.mysociety.org/about/history/>
- Citizens make society — mySociety, 22 July 2020, on why the parent name is plain. <https://www.mysociety.org/2020/07/22/citizens-make-society/>

A name in that convention would be judged on whether a BSL user, a council officer and a select-committee clerk can all say it, spell it, and know it is *not* NHS England.

Illustrative directions only — not a shortlist, not cleared:

| Direction | Example shape | What it signals | Risk |
|---|---|---|---|
| Second-person civic | WhereIsMyInterpreter / WhoBookedBSL | Fulfilment, not ideology | Interpreter-only scope; drops Deafblind / AIS contact-method half |
| Street-level fix | FixMyAccess / BookedNotThere | Same family as FixMyStreet | “Access” is generic |
| Scorecards cousin | BSL Scorecards / Council Sign Scorecards | Method already understood by officers who use Climate Scorecards | “Score” invites league-table fights |
| Plain gap, no official noun | SignedOut / StillWaiting | Lived-experience texture already in *Still Ignored* / *Locked Out* | Campaign tone; dossier rule is not to wear the banner |
| Host-first | “[Charity] BSL data” | Independence visible in the name | Ties the dataset to one org’s campaign positions |

**Working recommendation for the next naming pass (not a chosen name):** drop “Monitor”, “Compliance”, “Register” and “Accountability Tracker” from the public-facing string. Keep “BSL” if the product is BSL-first; keep “Deaf” + “Deafblind” in the subtitle so the name does not erase dual-sensory users. Put the official-sounding words in the *methodology page* (“how we score AIS compliance”) not in the masthead.
