# Prompt 47 — Existing published template letters and self-advocacy tools

**Master index prompt 47.** Compiled 9 September 2026. Templates-section batch. Do not draft a new letter until this catalogue is used. Dossier rule: stay unbiased; follow money and fulfilment.

**Question.** What already exists, so this project does not duplicate or contradict it?

**Headline.** A strong patient-facing **needs-notification** letter already exists (SignHealth, 2025, three variants including deafblind, with BSL explainer). A strong **complaint / letter-before-action** generator already exists (Disability Justice). RNID has a **hand-in card** and a how-to-complain page, not a fill-in letter. BDA, Action Deafness, Patients Association and NHS England do **not** publish a patient-to-NHS AIS letter. The real gap is not “a letter exists.” It is: a **dated-appointment booking request** that asks for in-person BSL rather than VRI, and a first request that is operational rather than campaign-toned or pre-action.

Default posture if a Templates section is built: **curate and link first**. Draft only where the catalogue shows a hole.

---

## What to do with this finding

| If the section is… | Do this |
|---|---|
| Needs flag / “record my communication needs” | Link SignHealth 2025 letter + RNID card. Do not write a rival. |
| Complaint that a past appointment had no support | Link Disability Justice generator + RNID/NHS.uk/Patients Association process pages. Optional thin wrapper only if those tools miss F2F-vs-VRI or PALS-first routing (prompt 46). |
| Letter before action / legal escalation | Do **not** publish a new one. Disability Justice already does this. Prompt 48/49 decide whether this site should even point at LBA language. |
| “Book an in-person interpreter for Tuesday, not VRI” | No strong national fill-in letter found. This is the only clean draft gap — and only after 48 and 49. |
| DeafBlind NHS specifically | SignHealth deafblind variant + Sense communication passport (passport, not a letter) + Sense LA assessment letter (social care, not AIS). |

## Gaps a new draft would have to justify

1. **Dated appointment, in-person not VRI.** Nobody publishes a short operational letter that names the appointment and asks the booking team / PALS to confirm a registered in-person interpreter. Prompt 46 says that is the legally grey, practically urgent ask.
2. **NHS complaints-procedure wrapper on a Deaf fact pattern.** Disability Justice is Equality Act / LBA. Patients Association is NHS complaints with no Deaf content. Nothing stitches “no interpreter on 12 March at St Helier outpatients” to the 2009 Regulations path in prompt 46.
3. **Code names.** Live SignHealth page still says DCB 1605. Current standard is DAPB1605 v4.0. A curated link should carry a one-line “the Standard’s current name is…” rather than a rewrite of their letter.
4. **DeafBlind NHS booking.** SignHealth has a deafblind **notification** variant. No public letter for RIDB / deafblind manual / communicator-guide booking at a named clinic.

Do not treat “no perfect letter” as “write five.” Link SignHealth + RNID card + Disability Justice, then decide after 48 and 49 whether the appointment-booking hole is worth one thin template.

---

## What a new template must not do

- Duplicate SignHealth’s notification letter with different branding.
- Publish an LBA that undercuts or contradicts Disability Justice.
- Cite DCB/SCCI as if current.
- Tell people AIS “makes VRI unlawful” (prompt 46).
- Use the MP-campaign letter as an NHS access letter.
