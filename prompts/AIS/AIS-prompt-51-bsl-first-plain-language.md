# Prompt 51 — BSL-first / plain language for the grassroots letter

**Master index prompt 51.** Last file in the Templates-section batch (46–51). Compiled 9 September 2026. The ideas-doc 3A layer is meant to be usable by someone whose first language is BSL. That is a design constraint, not a polish pass.

**Question.** Is there official or charity guidance for *this exact use case* — a fill-in letter a BSL-first person sends to the NHS — or only general plain-English / Easy Read / BSL-of-the-Standard material?

**Headline.** **Gap, not a substitute.** Nobody publishes a how-to for writing a patient-to-NHS AIS letter in a form a BSL-first user can independently fill. What exists is: SignHealth’s **BSL explainer of an English letter**; NHS England **BSL of the Standard itself**; screening-programme **BSL of NHS-to-patient letters** (wrong direction); Easy Read built for **learning disability**. AIS and Locked Out both say do not treat written English as access. A Templates section that ships only a dense legal letter fails 3A.

## 51.2 Design rules if this project ships any grassroots letter

These are constraints drawn from the sources above, not a claim that NHS England published a template spec.

1. **Two channels, always.** English letter the NHS can file + BSL video “what this letter says” and “how to send it.” SignHealth already proved the pattern. A letter-only page fails 3A.
2. **Do not pass off Easy Read-for-learning-disability as BSL access.** Flag the difference on the page. An ER twin can exist *as well* for users who want it.
3. **Boxes, not essays.** Name, address, NHS number, date of appointment, clinic, “I need a registered in-person BSL interpreter — yes/no.” Free-text optional and last.
4. **Reading age ~9–11 on the English side.** One idea per sentence. No “hereinafter,” no “pursuant to DAPB1605 v4.0.” Statute names in a short footnote or a “what the law is called” line, not in the asking sentence.
5. **How-to in steps, numbered, like SignHealth.** Pick / fill / send. Show email *and* print. Say “do this before the appointment.”
6. **DeafBlind is not a BSL-video afterthought.** Visual-frame / hands-on / large print / emailed plain text may be the actual access. SignHealth already splits a deafblind .docx. Keep that split.
7. **Do not ask the user to draft legal English they cannot check.** Prompt 48/49: the grassroots letter is a request, not an LBA. That also makes it shorter and safer to sign.
8. **Commission a registered Sign Language Translator** for any BSL twin. Do not generate BSL from an LLM and call it translation.

## 51.3 Words the English letter can keep / must drop

| Keep (plain) | Drop or move to a footnote |
|---|---|
| I am Deaf. I use British Sign Language. | “I am a disabled person for the purposes of s.6 Equality Act 2010” |
| Please put this on my record. | “Identify, record, flag, share and meet as per DAPB1605” |
| I need a registered interpreter in the room on [date]. | “Remote services are not a total replacement…” (true, but staff-facing) |
| Please email me. Do not phone. | “Alternative format correspondence in accordance with the Standard” |
| The interpreter did not come on [date]. | “This constitutes a failure to make reasonable adjustments and a breach” |

The NHS copy can still *name* the Equality Act and the Accessible Information Standard. Naming is not the same as pleading.
