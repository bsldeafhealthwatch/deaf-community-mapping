Subject: BSL & Deaf Health dossier — link to share, and a quick note on how it works

Hi team,

The evidence dossier is live. Here's the link to bookmark and use going forward:

https://bsldeafhealthwatch.github.io/deaf-community-mapping/dossier/bsl_dossier.html

A couple of things worth knowing about how this link works, so there's no confusion later:

**It's technically public, but not searchable or discoverable.** The site has to be hosted as a public GitHub Pages site (that's a requirement of the free plan), but I've blocked it from being indexed by Google or any other search engine, so it won't turn up in search results and nobody will stumble onto it by accident. In practice, the only way anyone reaches it is by having this exact link. Please treat the link itself as something to keep fairly low-profile — don't post it anywhere public (social media, public forums, etc.) — but sharing it directly with relevant colleagues or contacts is fine.

**From the dossier, you can also reach:**
- The stakeholder map
- A Documents page (FOI logs, research summaries)
- A Systems Comparison page (still provisional/unreviewed working documents)
- A Feedback page, if you want to flag anything back to me

**On editing:** the dossier has "Add" and "Edit" buttons in a few places, but a heads-up — those only save changes to your own browser, not to the live site for everyone. I'm the one publishing updates to the source file, so if you spot something that needs changing or adding, send it my way via the Feedback page or directly, and I'll get it into the next update.

New display options just went in too — there's now a Day/Night/Auto theme toggle and a Standard/Reader text-size option in the top bar, if that's useful for how you read it.

The link is mobile-friendly, so it works just as well from a phone as a laptop, and accessibility has been built in throughout — proper heading structure, keyboard navigation, screen reader support, and readable contrast in both light and dark mode.

One more thing worth flagging: my main focus throughout has been Deaf Health, but I've added quite a bit more alongside it that I think could be genuinely useful too — the Systems Comparison material, the wider stakeholder mapping, and so on. If anyone wants anything changed, updated, added, or removed, let me know and I'm happy to make changes whenever — no need to wait. Otherwise, we can go through it together at the next meeting.

Let me know if the link doesn't work for you or if anything looks off.

Thanks,
