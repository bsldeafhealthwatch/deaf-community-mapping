## 51. Domains 4, 5 and new Domain 18 — DWP/Jobcentre Plus prompts 20-33 verified against primary sources, and near-miss on prompt numbering corrected, 8 September 2026

This entry covers two related pieces of work carried out the same day. First, a numbering near-miss: an attempt to reconstruct "the original prompts 1-19" from memory of an unsaved chat produced a confident-looking but fabricated tracker (invented "resolved" statuses, no traceable source — one claim directly contradicted this file's own Section 33 finding on the £80-100m NHS cost figure). This was caught before anything was written into a domain file, and the actual cause was identified: prompts 1-19 never existed as a single sequentially-numbered document — they are `SUPERGROK_PROMPTS.md`'s Categories A1-A5/B1-B11/C1-C3 (5+11+3=19), referred to elsewhere by a shorthand that implied literal numbering. Both prompt files were corrected the same day: `SuperGrok_Research_Prompt_Pack.md` now carries a running prompt-numbering index (next free number stated explicitly) and `SUPERGROK_PROMPTS.md` now points to it. Six of the ten claims checked this pass were confirmed exactly against their primary source with zero discrepancies found — an unusually clean pass, credited to the source prompts' own discipline (explicit AIS-false-analogy warnings, "no reliable figure found" instructions, and a clear national-vs-local split) rather than to luck.
